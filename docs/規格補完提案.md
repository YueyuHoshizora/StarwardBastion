## 二、待定項目 2：20 張地圖

完整座標與俯視圖見 [附錄 A](附錄A_地圖資料.md)。

### 2.1 資料格式（可機器判定）

- `ground`：地面路線頂點序列，只允許水平或垂直線段；展開後的逐格序列就是敵人的實際行進路徑。
- `air`：空中航道頂點序列，允許水平、垂直或 45° 斜段。
- 每個相鄰格之間的線段都會記錄移動層級：只屬於地面路線的標為 `ground`，只屬於空中航道的標為 `air`，同時屬於兩者的標為 `ground`＋`air`（R8 共用段）。每張地圖至少有 2 段共用段。
- 入口是各路線的第一格，必須位在地圖邊緣；出口是基地。
- 格子狀態分為五種：`可建塔`、`道路`、`基地`、`主題禁建地形`、`邊陲荒地`（禁建）。

### 2.2 禁建區設計原則

1. **道路格與基地格一律禁建**（R1、R8）。地空共用段本身就是道路格，因此也禁建。
2. **只屬於空中航道的格子可以建塔**：航道是飛行層，底下仍是地面。畫面以虛線、箭頭與投影高度標出空中航道，所以塔放在底下也不會遮住航線。這項判定需要您確認（見第五節 Q1）。
3. **主題禁建地形**：每張地圖依主題放置 2–5 處地形，例如 M04 冰裂隙、M07 中央反應爐核心、M08 穹頂牆、M11 熔岩河、M14 船塢龍門架、M16 要塞牆。這些地形也用來切割可建區，形成各地圖的特色（附錄 A 逐項列出座標）。
4. **星級比例由邊陲荒地補足**：扣除道路格、基地格與主題地形後，程式會以 2×2 區塊為單位，把距離任一路線最近的格子設為可建塔格，直到剛好達到 `round_half_up(星級比例 × 非道路非基地格數)` 為止。其餘格子轉為邊陲荒地。結果是可建區都貼近路線、形狀完整、能實際放塔；遠離路線、沒有戰術價值的角落則成為荒地。
5. 每個可建區都至少能放下一座 2×2 塔，不會留下無法使用的零碎單格。

### 2.4 地空層級的畫面標示（R8，不只靠顏色）

- 地面道路：實心路面，兩側有邊線，路面上有行進方向的 `›` 刻紋。

- 多路線地圖（M12 等）：每條路線的入口旁顯示路線 ID 標籤（G1、G2、A1…）。游標指向入口時，會高亮該路線的完整行進路徑，讓實際敵人路線一目了然。

## 三、待定項目 3：每張地圖第 5–20 波編成

逐波資料見 [附錄 B](附錄B_波次編成.md)，共 20 張 × 20 波＝400 波。第 1–4 波依初稿固定；第 5–20 波由可重現的規則產生後定稿為明文資料 `src/data/waves.js`，之後可以逐波手動調整。

**產生與驗證規則**（自動測試逐波檢查）：

1. 每波主體數等於 `N(n)=6+⌊n/2⌋`；E10 子體不計入。
2. 每波敵種數不超過星級上限（★2／★★3／★★★4／★★★★5／★★★★★6），並隨波次逐步增加。
3. 登場下限：E04≥6、E06≥8、E09≥9、E10≥10、E11≥7、E12≥10、E13≥8、E14≥12、E15≥13、E16≥15；星級對早期波次的禁止條件全部符合。
4. 同一波內：重型（E03、E05、E08、E12、E14、E16）≤⌊N/3⌋；快速（E02、E07、E11、E13）≤⌊N/2⌋；隱形（E06、E15）≤⌊N/4⌋。
5. 每波至少包含一種不受數量上限限制的敵種，確保總數一定能分配完畢。
6. 敵種以「越久沒出現越優先」輪替；新解鎖的敵種在解鎖當波優先登場。空中主題地圖（M05、M13、M15、M16、M18、M20）提高空中敵人比重，地面主題地圖（M06、M11、M14）降低空中敵人比重。
7. 生成順序：一般 → 快速 → 隱形 → 護盾 → 分裂 → 重型。
8. 路線分派：同層級敵人依序輪替該層路線；多條路線共用同一入口時，共用一個出怪佇列。**每個入口每 1.0 秒生成一名**，高於規格下限 0.75 秒；不同入口可以同時生成。
9. T05 可負擔性：隱形敵人最早在第 8 波登場。第 1 波開始時已有 240 CR，超過 T05 造價 220 CR，因此任何隱形敵人登場前都已有足夠資源購買 T05。

> 平衡提醒：以上編成只保證符合規格規則，尚未經過 Gate B 實測。高星級地圖的地面路徑較短（M20 最長 20 格），壓力明顯較高。Gate B 會以模擬器對每張地圖執行至少 3 種建塔配置；若發現無法通關或可以用單一塔種割草，會在規則範圍內調整第 5–20 波，並把調整後的附錄 B 與紀錄一起交回。
