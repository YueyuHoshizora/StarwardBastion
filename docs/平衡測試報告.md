# 平衡測試報告（Gate B）

> 由 `node tools/balance.mjs` 產生，**請勿手改**。模擬器與遊戲本體共用 `src/core/game.js`，結果可重現（無亂數）。

## 測試方法

- 機器人只在波次之間操作：場上敵人清空後，依配置順序把資源允許的塔放在「射程內路線取樣點最多（越近基地權重越高）」的位置，再開始下一波；波次進行中不操作。
- 配置：
  - **C1 混合均衡**：開局 T01→T07→T05→T03→T01→T07→T06→T10→T02→T09→T12→T04→T08→T11，之後循環 T02→T07→T06→T09→T12→T03→T08→T04→T10
  - **C2 低價密集**：開局 T01→T07→T05→T01→T07，之後循環 T01→T07→T01→T01→T07
  - **C3 範圍控制**：開局 T01→T07→T05→T03→T11→T09，之後循環 T03→T09→T06→T11→T02→T08
  - **S1 單塔種 T10**：只建 T10
  - **S2 單塔種 T12**：只建 T12
- 割草風險判定（Gate B）：每個星級至少要有 1 張地圖**不能**以單一塔種（S1／S2）且不操作就無漏怪通關。
