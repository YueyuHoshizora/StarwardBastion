# 平衡測試報告（Gate B）

> 由 `node tools/balance.mjs` 產生，**請勿手改**。模擬器與遊戲本體共用 `src/core/game.js`，結果可重現（無亂數）。

## 測試方法

- 機器人只在波次之間操作：場上敵人清空後建塔、按下開始下一波，並立即以發放的津貼再建塔；波次進行中不操作。
- 選塔：下一波含隱形且 T05 數量不足時先建 T05；其餘依下一波空中／地面總 HP 比例，補足投資較少的一側。
- 回饋：上一波有隱形漏怪就把 T05 目標數加 1（最多 4 座，以 6.0 格偵測覆蓋地面路線選位）；有空中漏怪則對空投資比例提高 10%（最多 +40%）。
- 位置：射程內路線取樣點的邊際覆蓋最高處（越近基地權重越高、已被覆蓋的點權重遞減）。
- 配置：
  - **C1 混合均衡**：對地循環 T01→T03→T01→T06→T02→T10→T04→T12；對空循環 T07→T09→T07→T08
  - **C2 低價密集**：對地循環 T01；對空循環 T07
  - **C3 範圍控制**：對地循環 T01→T03→T06→T11→T03→T02；對空循環 T07→T09→T08
  - **S1 單塔種 T10**：只建 T10
  - **S2 單塔種 T12**：只建 T12
- 割草風險判定（Gate B）：每個星級至少要有 1 張地圖**不能**以單一塔種（S1／S2）且不操作就無漏怪通關。
